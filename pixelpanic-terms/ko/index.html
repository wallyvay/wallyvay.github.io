Pixel Panic
최종 업데이트: 2026년 8월 28일

Pixel Panic은 LI WEI가 제공하는 macOS 이미지 도구입니다. 앱을 사용하면 본 약관에 동의합니다. 첫 버전에는 구독, 앱 내 구입 또는 유료 Pro 등급이 없습니다.

사용하는 이미지, 텍스트, 프롬프트, API 계정과 결과에 대한 책임은 사용자에게 있으며 처리·업로드 권리가 있어야 합니다. 불법, 침해, 기만 또는 유해한 용도로 사용할 수 없습니다. AI 기능에는 제공업체의 약관, 요금, 지역 및 콘텐츠 규칙도 적용됩니다.

해당되는 경우 교체 전 결과를 검증하고 타임스탬프 백업을 만들지만 중요한 파일은 별도로 백업해야 합니다. 표지와 AI 결과는 일반적으로 새 파일로 저장됩니다. 생성 결과의 정확성, 고유성, 적법성 또는 특정 목적 적합성을 보장하지 않습니다.

법이 허용하는 범위에서 앱은 현재 상태로 제공됩니다. 제공업체 장애, 계정 요금, 인증 정보 분실, 부적절한 AI 결과나 간접 손실에 대해 개발자는 책임지지 않습니다. 변경 시 이 페이지의 날짜를 갱신합니다. 문의: wallyvay@gmail.com.
