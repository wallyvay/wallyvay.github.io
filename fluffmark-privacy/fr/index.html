Politique de confidentialité

Fluffmark
Dernière mise à jour : 30 juillet 2026

Fluffmark importe uniquement les médias que vous choisissez explicitement avec le sélecteur de photos du système. Le décodage des images, la modification des annotations, le rendu de l’aperçu et l’exportation sont effectués sur cet appareil. Dans cette version, Fluffmark ne téléverse ni vos médias d’origine ni vos documents d’annotation vers un serveur.

Les projets modifiables sont stockés dans le dossier Application Support local de l’app. Vous pouvez supprimer un projet ou effacer tout l’historique depuis l’écran d’accueil. Les résultats sont enregistrés dans Photos uniquement après avoir choisi Enregistrer dans Photos ; l’app demande un accès limité à l’ajout et n’a pas besoin d’accéder à toute la photothèque.

Si vous envoyez un avis, l’e-mail peut inclure la version de l’app, le type d’appareil, la version du système, la région, le fuseau horaire et la description que vous rédigez. L’envoi est assuré par votre service de messagerie configuré.
