Pixel Panic
최종 업데이트: 2026년 8월 28일

Pixel Panic은 크기 조절, 최적화, 형식 변환, 메타데이터 변경, 표지 렌더링과 결과 검증을 Mac에서 처리합니다. 개발자는 원본 이미지, 편집 내용, 파일 이름·경로 또는 폴더 보안 책갈피를 받지 않습니다.

AI 편집은 선택 사항이며 사용자가 설정한 지원되는 타사 AI 서비스를 이용합니다. 참조 이미지와 프롬프트는 Mac에서 제공업체로 직접 전송되며 해당 약관과 정책이 적용됩니다. 개발자는 요청을 중계하거나 API 키를 받지 않습니다. 인증 정보는 macOS 키체인에 저장됩니다. 중국 본토 App Store에서는 AI 편집을 사용할 수 없습니다.

진단 로그에는 앱 버전, 이벤트 이름, 오류 도메인·코드·유형이 기록될 수 있으나 키, Secret, 프롬프트, 이미지, 파일 이름과 경로는 기록하지 않도록 설계되었습니다. 사용자가 피드백을 선택한 경우에만 기기 정보, 작성 내용과 로그가 이메일에 포함되며 보내기 전에 수정하거나 제거할 수 있습니다.

계정, 광고, 제3자 분석 또는 추적이 없습니다. 평점 요청은 Apple StoreKit이 처리합니다. 설정에서 AI 인증 정보를 삭제할 수 있고 앱 데이터 삭제 또는 제거로 로컬 데이터를 없앨 수 있습니다. 문의: wallyvay@gmail.com.
