Pixel Panic

ينفّذ Pixel Panic تغيير الحجم والتحسين وتحويل التنسيق وتعديل البيانات الوصفية وإنشاء الأغلفة والتحقق من المخرجات على جهاز Mac لديك. ولا يتلقى المطوّر صورك الأصلية أو تعديلاتك المحلية أو أسماء الملفات أو مساراتها أو إشارات المجلدات ذات النطاق الأمني.

التحرير بالذكاء الاصطناعي اختياري ويستخدم المزوّد الذي تهيئه: Google أو Gemini أو ChatGPT أو Doubao أو Kling. عند إرسال تعديل، تُرسل الصورة المرجعية والمطالبة مباشرة من جهاز Mac إلى ذلك المزوّد وتخضع لشروطه وسياسة الخصوصية لديه. لا يعمل المطوّر كوسيط لهذه الطلبات ولا يتلقى مفاتيح API الخاصة بك. تُحفظ بيانات الاعتماد في سلسلة مفاتيح macOS، بينما تُحفظ محليًا إعدادات النموذج ونقطة النهاية واللغة والمظهر والمحرر غير السرية.

قد يسجّل سجل تشخيص محلي إصدار التطبيق واسم الحدث ونطاق الخطأ ورمزه ونوعه. وقد صُمم بحيث لا يسجّل مفاتيح API أو الأسرار أو المطالبات أو محتوى الصور أو أسماء الملفات أو مساراتها. إذا اخترت إرسال ملاحظات، تُملأ رسالة البريد بطراز الجهاز وإصدار النظام والمنطقة والمنطقة الزمنية والوقت ووصف المشكلة وخطوات إعادة حدوثها، وقد يُرفق ذلك السجل. يمكنك تعديل الرسالة أو إزالة المرفق قبل الإرسال، ويتولى مزوّد البريد لديك عملية التسليم.

لا يحتوي Pixel Panic على نظام حسابات أو إعلانات أو تحليلات من جهات خارجية أو تتبّع. ويتولى Apple StoreKit طلبات التقييم. يمكنك حذف بيانات اعتماد الذكاء الاصطناعي من الإعدادات، وإلغاء الوصول إلى المجلدات بحذف بيانات التطبيق المحفوظة، وحذف البيانات المحلية الأخرى بإلغاء تثبيت التطبيق. يمكن إرسال الأسئلة إلى wallyvay@gmail.com.
